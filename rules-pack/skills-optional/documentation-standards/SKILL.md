# Apply Documentation Standards

Read `docs/AGENTS.md`, root rules, and the owning source before editing. Classify human-facing documents as tutorial or reference. Give every fact one home; keep full detail at the owning level and link from higher-level pages.

Before moving or deleting a page, search inbound references and update every target and fragment in the same change. Keep Agent Notes for rationale and proposals, not stable documentation. Generated catalogs change through their source or generator. When a budget is red, relocate, then condense, then raise a ceiling only with a recorded reason. Run project documentation gates and report the scope and checks actually run.
