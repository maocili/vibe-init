# Apply the Prose Standard

Preserve the complete proposition: actor, action, conditions, timing, modality, exceptions, ownership, failure, and consequence. Remove decoration, duplication, and narration only after every necessary fact survives.

Comments explain non-obvious contracts or rationale that code cannot express; they do not restate code. Keep local behavior, failure, ownership, and safe-use facts where readers need them, and link to the single home for architecture or history. Treat visible wording as behavior and validate it through the relevant output. Exclude generated artifacts and sealed archived notes; change the owner before derivatives.
