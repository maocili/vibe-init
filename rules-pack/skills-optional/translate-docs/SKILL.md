# Translate Documentation Pairs

Use only by explicit invocation. Read pairing policy and terminology before translation. For an existing pair, edit only the smallest aligned units and preserve reviewed text outside the diff. For a new pair preserve heading structure, list and table order, link targets, code spans, and fenced code where policy requires it.

Check both sides clause by clause, then read the counterpart independently for natural technical prose. Record the pair only after that check, run the scoped pairing verifier and project doc gate, and never translate sealed archived note triplets.
